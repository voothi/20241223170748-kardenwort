# Product Overview

**Kardenwort** is an intelligent command-line utility for language learning that automatically creates context-rich flashcards for Anki from any text source.

## Core Purpose
- Deconstructs text and extracts vocabulary with intelligent lemmatization
- Transforms books, articles, or any text into structured vocabulary lists
- Specializes in grammatically complex languages like German with compound word splitting
- Operates completely offline for privacy and reliability

## Key Capabilities
- **Intelligent NLP Processing**: Uses spaCy for accurate lemmatization and tokenization
- **German Language Expertise**: Advanced compound word splitting and separable verb handling
- **Dual Card Types**: Creates both vocabulary cards (individual words) and sentence cards (full context)
- **User-Trainable System**: Fine-tune results with `lemma_override.tsv` files
- **Anki Integration**: Direct import into Anki with hierarchical deck creation
- **GoldenDict Integration**: On-the-fly vocabulary extraction from dictionary lookups

## Philosophy
- **Separating Reading from Study**: Split content consumption and vocabulary acquisition into focused activities
- **Medium Independence**: Companion tool that works with any source material
- **Offline First & Privacy**: All processing happens locally
- **Simple is Not Easy**: Complex linguistic analysis provides simple, actionable results

## Multi-Language Support
Currently supports English (en) and German (de) with extensible architecture for additional languages.
