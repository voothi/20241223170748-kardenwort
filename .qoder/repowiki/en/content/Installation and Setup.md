## Prerequisites

Before installing the Kardenwort system, ensure the following prerequisites are met:

- **Python 3.9**: This specific version is strongly recommended. Using Python 3.9 avoids potential compilation issues that may arise with newer versions (e.g., 3.10+) on Windows, which often require a C++ compiler toolchain (such as Microsoft Visual Studio Build Tools) to install native dependencies. For a seamless setup on Windows, it is advised to install Python 3.9 directly from the Microsoft Store, which provides pre-compiled binaries and eliminates the need for additional development tools.

- **Anki Desktop**: The Anki application must be installed and running on your system. Kardenwort integrates directly with Anki to import generated flashcards.

- **AnkiConnect Add-on**: Install the AnkiConnect add-on from the official AnkiWeb repository. This add-on enables programmatic communication between external applications and Anki.

- **Modified AnkiConnect for Deck Descriptions**: A critical dependency for the automatic population of Anki deck descriptions is a modified version of AnkiConnect. The standard AnkiConnect add-on does not support this feature. To enable automatic deck descriptions, download and install the modified version from the following repository: **[https://github.com/voothi/20251110002755-anki-ankiconnect](https://github.com/voothi/20251110002755-anki-ankiconnect)**. Without this modified version, all other Kardenwort features will function correctly, but the `--anki-deck-content` functionality will be unavailable.

## Repository Cloning and Ecosystem Setup

Kardenwort is part of an ecosystem of three interconnected repositories. These must be cloned into a common parent directory to ensure proper integration.

1.  Create a new directory to serve as the ecosystem root (e.g., `kardenwort-ecosystem`).
2.  Navigate into this directory and clone the three required repositories using the following commands:

```bash
mkdir kardenwort-ecosystem
cd kardenwort-ecosystem
git clone https://github.com/kardenwort/20250913122858-kardenwort.git
git clone https://github.com/kardenwort/20250913123240-kardenwort-anki-csv-importer.git
git clone https://github.com/kardenwort/20250913123501-kardenwort-anki-templates.git
```

The final directory structure should resemble the following:
```
kardenwort-ecosystem/
├── 20250913122858-kardenwort/
├── 20250913123240-kardenwort-anki-csv-importer/
└── 20250913123501-kardenwort-anki-templates/
```

This structure is essential for the relative path configurations used by the system.

## Anki Template Import

To use the generated flashcards effectively, the Kardenwort Anki card template must be imported into your Anki profile.

1.  Navigate to the `20250913123501-kardenwort-anki-templates` repository directory.
2.  Go to the `decks-for-first-initialize-templates` subdirectory.
3.  Select the latest version folder (e.g., `v1.0.0`).
4.  Choose one of the `.apkg` deck package files within that folder.
5.  Open Anki Desktop and use the "Import" function (File > Import) to import the selected `.apkg` file.

This process will install the required note type and card template, which are designed to display context, audio, and other rich information generated by Kardenwort.

## Virtual Environment and Dependency Installation

A shared virtual environment is used to manage Python dependencies for the entire ecosystem, keeping the project directories clean and ensuring consistent package versions.

1.  Navigate into the main Kardenwort project directory:
    ```bash
    cd 20250913122858-kardenwort
    ```

2.  Create a virtual environment in the parent directory (one level above the project):
    ```bash
    python -m venv ../20250914043440-kardenwort-spacy-env
    ```

3.  Activate the virtual environment:
    -   **Windows (PowerShell):**
        ```bash
        ../20250914043440-kardenwort-spacy-env/Scripts/Activate.ps1
        ```
    -   **macOS/Linux:**
        ```bash
        source ../20250914043440-kardenwort-spacy-env/bin/activate
        ```

4.  With the virtual environment active, install the required Python packages:
    ```bash
    pip install -r requirements.txt
    ```

5.  Download the necessary spaCy language models for English and German:
    ```bash
    python -m spacy download en_core_web_lg
    python -m spacy download de_core_news_lg
    ```

These models are essential for the natural language processing tasks performed by Kardenwort, including sentence tokenization, lemmatization, and part-of-speech tagging.

## Configuration File Setup

The `config.ini` file controls the behavior of the `kardenwort_runner.py` script, particularly the paths to key components.

1.  While in the `20250913122858-kardenwort` directory, copy the template file to create the configuration file:
    ```bash
    copy config.ini.template config.ini
    ```
    (On macOS/Linux, use `cp config.ini.template config.ini`)

2.  Open `config.ini` in a text editor. The `[environment]` section contains the critical paths:
    -   `python_executable`: This should point to the `python.exe` (or `python`) executable within your virtual environment. The default value `../20250825231214-spacy-env/Scripts/python.exe` is an example; you must update it to match the name of your virtual environment (e.g., `../20250914043440-kardenwort-spacy-env/Scripts/python.exe` for Windows).
    -   `kardenwort_workspace`: This should be `./`, indicating the current directory.
    -   `importer_workspace`: This should point to the `kardenwort-anki-csv-importer` repository. The default `../20250401192017-anki-csv-importer` is an example; update it to `../20250913123240-kardenwort-anki-csv-importer`.

The use of relative paths makes the configuration portable. The `_config_loader.cmd` script is used by the batch files to parse these values.

## Test Commands and Verification

After completing the setup, verify the installation with a test run.

1.  Ensure Anki Desktop is running with the **modified** AnkiConnect add-on installed.
2.  Ensure your virtual environment is active.
3.  Add a short piece of German text to the `source_texts/text1.txt` file.
4.  From the root of the `20250913122858-kardenwort` project, execute the following command:
    ```bash
    python src/kardenwort/core/kardenwort_runner.py --type word --mode single --language de
    ```
    This command processes the text in `text1.txt`, creates vocabulary cards, and attempts to import them into Anki.

If the process completes successfully, a new deck should appear in Anki. A success message may also be displayed, depending on the configuration.

## Troubleshooting Common Issues

- **C++ Compiler Required (Windows)**: If you encounter errors about missing `vcvarsall.bat` or a C++ compiler when installing dependencies, you are likely using a Python version higher than 3.9. Uninstall the current Python version and reinstall **Python 3.9** from the Microsoft Store to resolve this.

- **Path Resolution Problems**: Ensure that the paths in `config.ini` are correct and use the appropriate path separators for your operating system (forward slashes `/` or double backslashes `\\` on Windows). Verify that the virtual environment directory name matches the one specified in `python_executable`.

- **AnkiConnect Connectivity Errors**: If the script fails to connect to Anki, verify that:
    - Anki Desktop is running.
    - The AnkiConnect add-on is installed and enabled.
    - The **modified** version of AnkiConnect is installed if you require deck description functionality.
    - No firewall is blocking the connection (AnkiConnect uses port 8765 by default).

- **Environment Activation Issues**: On Windows, if you receive an error about script execution being disabled when running `Activate.ps1`, you may need to change the PowerShell execution policy. Run PowerShell as an administrator and execute: `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`.

- **Dependency Conflicts**: Always use a virtual environment to isolate Kardenwort's dependencies. If conflicts arise, delete the virtual environment directory and recreate it following the installation steps.
