# RFC: v1.46.2 - Kardenwort Synchronization for Destination Highlighting

## Overview
This release synchronizes the `kardenwort` core engine with the latest Anki template features (v1.46.2) by adding support for explicit destination highlighting data.

## User Request
- **20260214150824**: Request to synchronize Kardenwort documentation and versioning with the templates release.

## Implementation Details

### 1. CSV Structure Update
- Added `WordDestinationInflectedForm` as the 83rd field in the `get_anki_csv_header()` function.
- This field is intended to store inflected forms or phrases that should be highlighted in the `SentenceDestination` and `SentenceDestination2` fields on the back of Anki cards.

### 2. Export Logic
- Updated `kardenwort.py` row generation loop to initialize rows with 83 columns.
- Ensured that the new field index is properly mapped during TSV generation.

## Verification
- Verified that the generated TSV file contains 83 columns.
- Verified that the header matches the template's expected field order.
